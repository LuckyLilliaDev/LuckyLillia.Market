# LuckyLillia 插件市场的登记仓库。

## 注册插件

1. 必须先将插件发布到 npm。

2. 在本仓库创建「注册插件」Issue，填写 npm 包名，并从下拉框选择插件分类。

3. 检查通过后，机器人创建包含 `plugins.json` 变更的 PR 并自动合并，几分钟后插件出现在市场，Issue 随之关闭。
如果检查不通过，机器人会在 Issue 下面回复具体不通过问题。发布新版本后可以通过新增评论重新检查。

## 维护者手动批准

AI 审查暂缓或审查服务出错时，有本仓库写权限的维护者可以在登记 Issue 下回复 `/approve`（后面可附说明），跳过 AI 审查直接登记并自动合并。npm 包信息、icon 和截图仍照常检查；没有写权限的人回复 `/approve` 只算普通评论。

自动合并失败（例如同时有别的登记修改了目录）时，PR 会保留并等待维护者合并，也可以再次回复 `/approve` 重试。
